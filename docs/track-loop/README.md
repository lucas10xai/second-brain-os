# Kỹ thuật vòng lặp (Loop engineering)

Hệ thống điều khiển bao quanh Agent: điều kiện dừng, bộ phản biện (critics), vệ sinh ngữ cảnh — và một vòng lặp chạy qua đêm bạn có thể hoàn toàn yên tâm khi thức dậy vào sáng hôm sau.

Sổ tay chuyên sâu cho [học phần 2](../course-2-loop/README.md) của khóa học AI Agent: học phần dạy khái niệm cốt lõi một lần; sổ tay này lưu giữ toàn bộ danh mục kỹ thuật, công cụ và bài thực hành. Đọc trên trang web hoặc tra cứu bất kỳ bài nào dưới đây.
