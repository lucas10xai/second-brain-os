# Cẩm nang hướng dẫn

Mười chương tài liệu, được sắp xếp theo đúng trình tự bạn thực sự xây dựng hệ thống: hiểu rõ mô hình, thiết lập môi trường, nạp dữ liệu, định hình cấu trúc, vận hành đồ thị, tự động hóa, truy vấn thông tin, khai thác đầu ra, duy trì sức sống cho hệ thống và khắc phục khi có sự cố.

Toàn bộ mười chương đã được biên soạn hoàn chỉnh. Trang [lộ trình (roadmap)](ROADMAP.md) phác thảo chi tiết nội dung từng trang tại một nơi duy nhất, đồng thời là nơi để đề xuất thêm các trang mới.

| Chương | Nội dung chính |
|---|---|
| [Khái niệm](01-concepts/README.md) | mô hình hoạt động cốt lõi và lý do các hệ thống ghi chú kiểu cũ thất bại |
| [Thiết lập](02-setup/README.md) | Obsidian, Claude Code, CLAUDE.md, MCP, dự án, Git |
| [Thu thập dữ liệu (Ingestion)](03-ingestion/README.md) | bài viết web, video, PDF, lịch sử trò chuyện, ghi âm giọng nói, nạp dữ liệu tồn đọng |
| [Cấu trúc hóa](04-structuring/README.md) | các loại trang, quy tắc liên kết, lược đồ chuẩn (schema), xử lý mâu thuẫn |
| [Đồ thị tri thức](05-graphs/README.md) | mục đích của đồ thị, liên kết phân loại, GraphRAG, các chỉ số đo lường |
| [Tác tử (Agents)](06-agents/README.md) | phân vai, lập lịch tự động, Hooks, Guardrails |
| [Truy xuất (Retrieval)](07-retrieval/README.md) | các mẫu câu hỏi truy vấn, công cụ tìm kiếm, ngân sách ngữ cảnh (context budget) |
| [Đầu ra (Outputs)](08-outputs/README.md) | viết bài, lập báo cáo nghiên cứu, xuất bản, học tập chủ động |
| [Bảo trì (Maintenance)](09-maintenance/README.md) | kiểm tra lỗi (Lint), nhịp độ rà soát, Git, quyền riêng tư, mở rộng quy mô |
| [Xử lý sự cố](10-troubleshooting/README.md) | những lỗi phổ biến ai cũng gặp phải và cách khắc phục triệt để |
