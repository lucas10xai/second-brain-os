# Kỹ thuật đánh giá (Eval engineering)

Đo lường là kỷ luật cốt lõi của sản phẩm AI: bộ dữ liệu chuẩn (golden sets), giám khảo không nói dối, quỹ đạo thực thi của Agent — và tự xây dựng bộ đánh giá đầu tiên chỉ trong một buổi chiều.
