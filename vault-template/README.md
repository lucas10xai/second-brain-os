# vault-template

Một vault khởi đầu (starter vault). Hãy sao chép thư mục này vào đâu đó trên máy của bạn, mở nó trong Obsidian dưới dạng một vault, và khởi động Claude Code bên trong đó.

```bash
cp -r vault-template ~/brain
cd ~/brain
claude
```

`CLAUDE.md` là bản chỉ dẫn mà agent sẽ đọc trong mỗi phiên làm việc. Hãy đọc nó trước lần chạy đầu tiên và chỉnh sửa những phần chưa khớp với cách tư duy của bạn. Các quy tắc mặc định cố tình được thiết kế nghiêm ngặt về việc tạo liên kết và không bao giờ ghi đè lên các điểm mâu thuẫn, bởi vì hai yếu tố đó chính là ranh giới phân biệt một vault có khả năng tích lũy tri thức với một thư mục chỉ chứa các bản tóm tắt rời rạc.
